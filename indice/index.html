O que vale saber antes de mexer

  • Toda página existe em dois subdomínios. exp-fb para o tráfego do Meta e exp-gg para o do Google, servidos do mesmo repositório. Publicar uma vez atualiza os dois.
  • Os leads ainda não separam por origem. O campo key do env-config.js continua "dev" nos dois deploys, então o landing_subdomain chega igual vindo do fb e do gg. Para separar de verdade falta configurar o build command com SITE_KEY em cada projeto do Cloudflare Pages — isso é no painel, não no código.
  • As três páginas do Manual são idênticas fora da oferta. Qualquer ajuste de copy ou layout precisa ser aplicado nas três.
  • As três do Mãos Lucrativas compartilham o mesmo CSS e o mesmo JS. Um ajuste de identidade vale para as três de uma vez.
  • Nenhuma página está indexável. Todas saem dos buscadores pelo _headers e por meta robots. Quando alguma for publicada de verdade, é preciso remover as duas coisas.
  • Os links legais do rodapé respondem 404 — em todas as páginas, e também no /taping, de onde o rodapé veio. Falta publicar as páginas de política de privacidade e termos de uso.
